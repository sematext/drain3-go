# Reproduce the Rust comparison

The reference is Rust `drain3` at `9d5e8e8cad620bc2b83064e8c67e29affccf571c`. Its source and verification dependencies are pinned in `rust/Cargo.lock`. These tools are not dependencies of the Go library.

## Compare synthetic traces

Run from the repository root:

```sh
mkdir -p /tmp/drain3-go-check
go build -o /tmp/drain3-go-check/go-trace ./internal/trace
cargo build --release --locked --manifest-path bench/rust/Cargo.toml \
	--target-dir /tmp/drain3-go-check/rust-target
python3 bench/parity.py \
	--go /tmp/drain3-go-check/go-trace \
	--rust /tmp/drain3-go-check/rust-target/release/drain3-go-reference
```

The command compares all training steps, final clusters, exact matches, and extracted parameters across 143 cases. It exits nonzero on a mismatch. The inputs are deterministic synthetic strings generated by `parity.py` with seed 27846.

To regenerate the checked-in expectations after a deliberate reference change, add `--write-golden testdata/rust-golden.jsonl`. Expectations come from Rust, not from the Go implementation. Update the pinned revision and tests together when changing references.

## Scope

Parity is self-verification. It is not an independent review or proof for every input. It excludes Rust LRU eviction, persistence, Unicode-version differences, and regex constructs without equivalent Go semantics. Those differences are listed in the root README.

Do not put customer corpora, raw templates, or private benchmark outputs in this repository. Keep comparison inputs and artifacts in a separate private directory.
